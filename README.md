# 省人康复7.20

二、康复医师

组织团队线上开展患者首次康复评估

若首次康复评估结果不确定，再次组织团队进行线上评估

通过 AI 智能设定康复目标，或手动调整康复目标

将康复目标同步给治疗师

基于 AI 智能更新或生成康复方案

组织团队会议确认康复方案

确认 AI 生成的康复处方建议

在康复治疗全程持续对患者进行康复评估

当患者满足出院条件时，通过 AI 智能生成二级方案（院外康复方案）

调整并确认二级方案

三、治疗师

对康复评估结果进行判断并确认

支持自定义调整 AI 智能调整后的康复治疗目标

手工调整资源管理平台 AI 自动生成的排班

确认或调整 AI 生成的康复处方

接收 AI 智能推送的康复任务

执行康复处方（涵盖 PT、OT、ST 类别）

记录患者每日康复执行情况，包括每日工作小结、打卡、治疗记录、药物变动等

四、护士

接收 AI 智能推送的护理任务

为患者开展康复护理（包含给药操作）

对患者进行康复宣教

这是梳理出来的各角色要做的事项，请结合这些功能事项帮我生成各角色的移动APP端，预览要有一个手机模型预览。我还会给你补充一个完整的交互业务流程。以丰富这个产品，所有的预览页面的操作按钮，工作台等均要有交互页面。
